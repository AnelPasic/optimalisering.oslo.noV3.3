# Egendefinerte globale innholdsseksjoner

Opprett nye seksjoner direkte i Pages CMS under **Global Innhold → Egendefinerte seksjoner**. Velg deretter **Global innholdsseksjon** i Innholdsseksjoner på en eller flere sider. Ingen promotering, kopiering eller GitHub Action.

Hver JSON-fil inneholder en ordinær innholdsseksjon med unik ID og automatisk UUID. Filnavn og `id` må være identiske. **Ikke endre ID eller slett en kilde som brukes på sider.** Felles innhold og formatering redigeres kun her; skjuling/flytting gjøres på hver side.

De åtte beskyttede globale elementene er separate og må fortsatt redigeres via sine eksisterende editorer. Kundecaser, priser og skjemaer skal ikke dupliseres her.
