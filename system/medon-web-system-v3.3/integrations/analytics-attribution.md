# Analytics & Attribution

## Launch requirement

A commercial site is not done until its primary conversion can be measured.

## Track meaningful events

Examples:
- primary CTA click;
- lead form start;
- lead form submit;
- assessment start/submit;
- package selection;
- phone click;
- email click;
- checkout/purchase where applicable.

Avoid event spam that nobody will use.

## Attribution lenses

Use:
- UTMs;
- analytics;
- ad-platform IDs;
- landing page;
- first/last touch where available;
- self-reported attribution;
- lead backend;
- CRM/accounting revenue truth.

Never sum conversions reported independently by multiple platforms and call that customers.

## Storage

Capture source data at lead creation so it survives beyond browser analytics.

## Feedback

Use downstream quality/revenue data to judge campaigns and pages, not raw lead count alone.
