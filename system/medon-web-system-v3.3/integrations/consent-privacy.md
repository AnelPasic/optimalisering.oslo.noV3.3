# Consent & Privacy

## Principle

Implement the actual privacy requirements of the trackers, forms and processors used. Do not copy a generic cookie setup that does not match the site.

## Before launch inventory

- analytics;
- ad pixels;
- embedded video/maps;
- chat/widgets;
- form processors;
- CRM/lead backend;
- CMS;
- hosting/CDN;
- newsletter;
- external fonts/assets.

## Rules

- minimize personal data;
- do not put PII in Git;
- do not expose write tokens/secrets to the browser;
- document retention;
- provide deletion/export workflow where required;
- keep privacy copy aligned with actual technical behavior.

Legal/compliance specifics should be reviewed against current requirements for the project.
