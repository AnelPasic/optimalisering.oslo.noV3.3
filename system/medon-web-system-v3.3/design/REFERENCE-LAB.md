# Reference Lab

Use supplied `design.md`, reference files or measured sites as controlled design inputs.

## Normalize each reference into layers

- typography;
- palette roles;
- geometry/grid/width;
- spacing/rhythm;
- component language;
- imagery/visual role;
- motion;
- what is brand-specific/non-transferable.

## Mode A — REFERENCE_REPLICA

Internal study only. Apply a reference's design DNA as faithfully as practical to the **same project content** to understand what the system does.

Never treat this as automatic production approval.

## Mode B — REFERENCE_TRANSFER

Production candidate. Transfer useful principles while adapting brand-specific signatures to the project.

## Controlled comparison rule

Every comparison uses identical:
- copy;
- structure;
- viewport;
- content density;
- proof state.

Change one major variable at a time.

## Font fidelity

Classify:
- `EXACT` — actual licensed/available font loaded;
- `METRIC_SUBSTITUTE` — available substitute tuned for similar metrics;
- `CHARACTER_MATCH` — similar visual character only.

Never claim 1:1 typography when the proprietary font is absent.

## IP/brand guardrail

May transfer principles such as hierarchy, rhythm, token roles and component logic.

Do not blindly copy:
- logos;
- proprietary illustrations/assets;
- unlicensed fonts;
- distinctive branded compositions wholesale.
