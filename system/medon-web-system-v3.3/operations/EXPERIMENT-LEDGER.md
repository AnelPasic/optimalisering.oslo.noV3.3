# Experiment Ledger

Store important SEO/CRO/design hypotheses and outcomes so Medon builds a real evidence base.

## Record

```text
EXPERIMENT ID:
Site/page/query/segment:
Hypothesis:
Evidence behind hypothesis:
Baseline:
Intervention:
Start/end:
Primary KPI:
Guardrail metrics:
Control/comparison if possible:
Result:
Confounders:
Conclusion:
Repeatable? unknown / likely / no
Follow-up:
```

## Test rigor

- high traffic/conversions → controlled A/B tests where appropriate;
- medium traffic → fewer/larger hypotheses + longer windows;
- low traffic → heuristic QA, user testing, behavior evidence, before/after measurement and larger coherent improvements.

A hypothesis without evidence and a KPI is an opinion, not an experiment.
