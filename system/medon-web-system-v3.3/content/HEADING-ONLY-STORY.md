# Heading-Only Story

Before body copy, write the page as:

```text
H1
subhead
H2 + one-line takeaway
H2 + one-line takeaway
H2 + proof/data cue
H2 + one-line takeaway
closing CTA
```

Then remove body copy and test whether the argument still makes sense.

The sequence should communicate, where relevant:
- main result;
- relevance/problem;
- why it matters;
- mechanism/differentiation;
- proof;
- what happens/how it works;
- next step.

Avoid template headings such as “Our Services”, “Why Choose Us”, “Our Process” when a more informative heading can carry the story.

Fail if body copy is required merely to understand what each section is trying to say.
