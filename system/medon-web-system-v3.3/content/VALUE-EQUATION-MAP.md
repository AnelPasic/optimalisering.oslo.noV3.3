# Value Equation Map

Use the Value Equation as a diagnostic lens, not a requirement to cram four promises into one headline.

## Map

```text
Dream Outcome
- What does the buyer ultimately want?
- Is it concrete enough to matter?

Perceived Likelihood
- Why should they believe this can work for them?
- Which proof/mechanism increases certainty?

Time Delay
- When does useful value begin?
- What can be said truthfully about speed?

Effort & Sacrifice
- What does the buyer need to do, learn, change or risk?
- What can legitimately be made easier?
```

## Coverage review

Rate coverage 0–10 only as an internal diagnostic. A weak dimension should produce a concrete action:
- weak likelihood → proof/mechanism, not bigger typography;
- weak time → clearer process/first-value step, not invented turnaround;
- weak effort → reduce form/process/friction, not vague “easy” copy.

## Rule

The page can distribute the equation across hero, proof, process, pricing, FAQ and CTA. The H1 does not need to carry everything.
