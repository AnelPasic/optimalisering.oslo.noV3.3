# Evidence Distribution / AIO Surface Plan

Use only for strong first-party material that deserves wider distribution.

## Principle

Optimize the information ecosystem, not just one webpage.

Do **not** manufacture consensus, fake awards, fake reviews, fake accounts or coordinated spam.

## For each strong asset ask

Where would this information naturally be useful?
- own canonical page;
- YouTube/video;
- LinkedIn;
- relevant forum/community contribution;
- case study/documentation;
- trade media / digital PR;
- partner/association profile;
- GBP/local profile where relevant.

## Native adaptation

Reuse the underlying facts, not the exact same commodity text everywhere.

Each distribution surface should provide native value.

## Retrieval mapping

When AI/search citations matter, observe:
- source types that recur;
- domains that recur;
- entities/facts that recur;
- where the brand is mentioned but not cited;
- where third parties are cited about the brand/topic.

Use this to discover legitimate participation/PR/content opportunities.

## Metrics

Keep separate:
- mention;
- citation/link;
- organic ranking;
- AI visibility;
- referral/click;
- lead/conversion.
