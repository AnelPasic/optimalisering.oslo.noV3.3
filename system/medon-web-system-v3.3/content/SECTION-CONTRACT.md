# Section Contract

Layout must follow the communication job.

For each important section define:

```text
SECTION:
PURPOSE: explain value / establish relevance / demonstrate mechanism / prove result / answer objection / reduce risk / compare options / convert

BUYER QUESTION ANSWERED:
BELIEF BEFORE:
BELIEF AFTER:
PRIMARY MESSAGE:
VALUE EQUATION ROLE:
CLAIM(S):
PROOF / SOURCE:
PROOF STRENGTH:
WHAT USER SHOULD NOTICE FIRST:
DESIRED NEXT STEP / NEXT QUESTION:
BEST INFORMATION FORM:
LAYOUT IMPLICATION:
DO NOT:
```

## Layout vocabulary

- statement → open space / strong type;
- comparison → side-by-side/table;
- choice → cards/selector;
- process → sequence/steps;
- data → number/chart/table;
- proof → result/case/review/evidence;
- explanation → text + explanatory visual;
- qualification → assessment/selector;
- action → form/CTA.

A card is not the default container for a paragraph.

Flag sections with no clear purpose or repeated purpose that adds little value.
