# Persuasion Sequence

Section order follows the visitor's questions and awareness, not a universal template.

Possible question chain:

```text
What is this?
→ Why should I care?
→ Is this problem relevant to me?
→ How much can it matter?
→ What do you actually do?
→ Why should I believe you?
→ How hard/risky is this for me?
→ What does it cost / what affects price?
→ What happens next?
```

Different traffic changes the order:
- high-intent search/paid search → proof, offer and action earlier;
- informational organic → answer/explanation/comparison/evidence before harder CTA;
- cold social → context/problem recognition before decision;
- branded/direct → less category education, more differentiation/trust.

Every section should naturally create or answer the next relevant question.
