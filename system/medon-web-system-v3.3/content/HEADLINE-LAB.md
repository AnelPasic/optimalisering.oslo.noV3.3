# Headline Lab

The agent must not accept the first plausible H1/H2.

## Step 1 — generate deliberately different mechanisms

For important heroes, generate roughly 12–20 raw candidates across relevant families:
- category clarity;
- outcome;
- problem → outcome;
- Value Equation;
- “Yay without Boo”;
- specificity;
- contrast;
- question;
- damaging admission;
- direct offer.

Do not force every family when it does not fit.

## Step 2 — hard gates

Disqualify/revise candidates that fail:
1. truth/compliance;
2. category/intent clarity;
3. ELI10 comprehension;
4. relevance to intended buyer;
5. proof compatibility when a result is implied;
6. locked project decisions.

## Step 3 — score survivors

Use `governance/SCORING-GATES.md` and page-role-specific weights.

For H1, clarity + relevance + believable outcome normally outweigh visual neatness.

## Step 4 — shortlist

Return 3–5 finalists with:
- validity status;
- scores;
- strongest reason;
- main trade-off;
- recommendation.

If one clearly wins, say so. If finalists are close, ask owner to choose.

## ELI10 test

ELI10 does **not** mean childish. A smart non-specialist should understand after one read:
- what this is;
- what they get;
- why it matters.

Necessary technical terms may remain if immediately explained in plain language.
