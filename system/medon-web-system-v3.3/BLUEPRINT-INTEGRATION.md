```text
Commercial Website Growth System
+

+
new content / architecture / QA rules

```

## Conflict rule

Verified business/project truth and v3 canonical rules override older raw source material and legacy examples.


## v3.3 governance delta

Technical Preflight, workflow profiles, Page Contracts, Search/AIO+CRO dual gates, Proof Router/site-ownership isolation, scoring gates, decision locks, Reference Lab, Red Team, canary scaling and Experiment Ledger are canonical v3.3 behavior.


## v3.3 production delta

Role Ownership, Content Operating Model, Visual Production Model, Git Content Flow and Implementation Agent Execution Contract supersede any older interpretation that one agent should own strategy, copy, design and code end-to-end, or that every internal content/design artifact needs owner approval.
