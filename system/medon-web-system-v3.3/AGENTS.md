# AGENTS — Medon Web System v3.3

## 0. Package boundary
v3.3 is self-contained. Do not ask for older general Medon packages.

## 1. Route before loading
Select project profile, assigned role and task route. Do not load every reference.

## 2. Role ownership is mandatory
Read `governance/ROLE-OWNERSHIP.md`. Do not cross role boundaries merely because the model is capable of doing so.

Default:
- Strategy/Content Agent → research, commercial/content, complete page drafts, content QA.
- Design role → controlled visual system and representative page.
- Implementation Agent → repo/code/CMS schema/components/tests/browser QA.
- Owner → consequential decisions.

## 3. Truth veto
Never fabricate claims, proof, results, ratings, clients, partnerships, urgency, scarcity, guarantees, prices, terms, platform capabilities or scientific precision.

## 4. Four commercial jobs
Important pages support BE FOUND, BE UNDERSTOOD, BE BELIEVED and BE CHOSEN.

## 5. Technical foundation before production code
Resolve framework/CMS/repo/hosting/deploy/runtime/leads/environments/ownership early. Git from first meaningful implementation commit on new coded projects.

## 6. Least-complex stack
Content site → Astro. Simple editing → Astro + Pages CMS. Rich editorial → Astro + Sanity. App-like product → Nuxt 4.

## 7. Page existence before URL
A keyword does not earn a page. Require distinct user need, real capability and useful information.

## 8. Content before implementation
For important commercial pages create coherent complete content under `content/CONTENT-OPERATING-MODEL.md`. Internal labs are agent tools, not automatic owner gates.

## 9. Implementation content boundary
Implementation agents must not invent final positioning, offers, public pricing, proof, claims or production copy unless explicitly assigned content authorship with an approved brief. Missing content stays a dependency.

## 10. Medon proof isolation
`MEDON_OWNED`: route approved Medon proof when relevant. `CLIENT_OWNED`: never inherit Medon proof.

## 11. Search/AIO + CRO parallel gates
Search intent/entities/information gain shape content early. Strong SEO cannot excuse weak conversion and vice versa.

## 12. Visual production
Use grayscale/IA before decorative styling. Use controlled visual changes, real content, desktop + mobile. Do not make each visual variable an owner meeting. Lock the system on a representative full page before scaling.

## 13. Owner interaction
Ask only material commercial/ownership/architecture/visible-brand decisions. Do not make the owner a token router.

## 14. Change control
Never silently reopen material locks. Use a Change Request with evidence/downstream impact.

## 15. Red Team independence
Red Team may fail and route work back. It may not silently edit during audit.

## 16. Existing-site CRO
Baseline → leak → device/context → behavior → qualitative why → evidence-backed hypothesis. Do not redesign from vibes.

## 17. Proof proximity
Match proof to the specific claim/objection near the doubt it resolves.

## 18. Content quality
Research competitors for consensus/gaps, not prose remixing. Prefer first-party facts/data/experience; check same-site redundancy and information gain.

## 19. AIO/reputation
Map retrieval/source ecosystems/query fan-out when useful. Build truthful corroboration; no fake consensus/community spam.

## 20. Mobile + real content
Every important content/design gate includes realistic mobile states, Norwegian copy lengths, forms, proof and package density.

## 21. Scaled publishing
Use template health + canary rollout. Stop when generator quality degrades.

## 22. Measurement
Commercial sites need end-to-end primary conversion measurement. Customer/revenue truth belongs in backend/CRM/accounting where available.

## 23. Launch readiness
No release with broken forms, unresolved production proof, missing tracking, accidental noindex, unresolved redirects or undefined deployment ownership.

## 24. Git content source of truth
Pages CMS edits Git-backed semantic content. Do not let stale hard-coded copy override locked content.

## 25. Learn
Record meaningful experiments. Prefer repeated Medon evidence over imported folklore once enough evidence exists.
