# Medon Web System v3.3

Self-contained production operating system for researching, writing, designing, building and improving commercial websites with **separated role ownership**.

v3.3 keeps the strongest v3.2 SEO/AIO/CRO/proof/technical rules and fixes the production model:

- Strategy/Content owns research, positioning and complete customer-facing content.
- Owner approves consequential wholes, not every eyebrow/button/section heading.
- Design uses controlled variables without turning every layer into an owner gate.
- Codex/Claude Code owns repo-native implementation and technical QA inside locked outcomes.
- Git is the shared source of truth; Pages CMS is the human editor over Git content.
- Fresh agent sessions should resume from concise project truth, not historical conversation noise.

## Default stack
- Astro Static — small Medon-managed/campaign sites.
- Astro + Pages CMS — default editable content sites.
- Astro + Sanity — richer editorial workflows.
- Nuxt 4 — application-like products.
