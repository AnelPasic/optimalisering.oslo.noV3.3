# START-HERE — Medon Web System v3.3

## Mission
Build commercial websites that are found, understood, believed and chosen — truthful, measurable, maintainable and appropriate for Norwegian/Nordic buyers.

## What changed in v3.3
v3.2 solved many research/governance problems but could still fail in two opposite ways: too much implementation-agent autonomy or too much owner micro-approval. v3.3 introduces explicit production ownership.

Read `WORKFLOW-v3.3.md` and `governance/ROLE-OWNERSHIP.md` before expanding work.

## Authority order
1. user's latest explicit instruction;
2. verified project/business facts;
3. approved material decisions + locked production content;
4. legal/compliance/security/privacy constraints;
5. project source-of-truth;
6. `BLUEPRINT.md`;
7. routed v3.3 rules;
8. approved visual/implementation profile;
9. implementation convenience.

Truth beats persuasion. Locked content beats stale hard-coded fallback copy.

## Workflow profiles
Choose `FAST`, `STANDARD`, `ADVANCED` or `EXISTING_SITE` using `governance/PROJECT-PROFILES.md`.

## Material approval gates
```text
0 Project + Technical Foundation
1 Commercial Truth
2 Search/AIO + Page Portfolio
3 Complete Content / Argument
4 CRO + Information Architecture
5 Visual System + Representative Page
6 Implementation + Technical QA
7 Red Team + Launch
```

These are not eight mandatory meetings. Agents resolve routine sub-decisions autonomously. Owner involvement is required only where `governance/OWNER-APPROVAL-MATRIX.md` says it is material.

## Core sequence
```text
project/profile → technical preflight → business truth → offer
→ Search/AIO + page portfolio
→ complete-page content production
→ content QA/lock
→ CRO/IA
→ visual brief + controlled system work
→ representative full page
→ implementation
→ independent red team + launch QA
→ measure/learn
```

## Content/code boundary
Production copy belongs in the semantic content layer where practical. Pages CMS edits Git content. The implementation agent must not invent missing commercial copy/claims/prices/proof.

## Decision discipline
Lock at meaningful granularity. Do not create a permanent decision artifact for every line of copy or spacing value.

## Current facts
Reverify volatile platform/search/price/plan/capability claims at implementation/publication time.
