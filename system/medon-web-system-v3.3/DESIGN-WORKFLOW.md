# DESIGN-WORKFLOW — v3.3

Design begins after the page argument and CRO/search structure are coherent enough to evaluate visually.

```text
complete/near-final representative-page content
→ grayscale information hierarchy / CRO structure
→ visual brief + reference transfer
→ controlled internal visual studies
   type → palette → geometry → components → imagery → rhythm
→ representative full page (desktop + mobile)
→ MATERIAL OWNER APPROVAL
→ template families
→ scale
```

Use one-variable comparisons when diagnosing uncertainty. Do not turn each visual variable into an automatic owner gate. See `design/VISUAL-PRODUCTION-MODEL.md`.
