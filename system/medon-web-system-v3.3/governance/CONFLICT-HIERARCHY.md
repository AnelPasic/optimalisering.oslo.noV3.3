# Conflict Hierarchy

## Tier 0 — absolute vetoes

No score can override:
1. factual truth;
2. legal/compliance constraints;
3. security/privacy;
4. explicit owner instruction within safe/legal bounds.

## Tier 1 — commercial viability pillars

These are **parallel minimum gates**, not a simple ranking:

```text
QUALIFIED DISCOVERABILITY  ↔  BUYER RELEVANCE  ↔  CONVERSION ABILITY
SEO/AIO/intent                ICP/JTBD              clarity/value/proof/CTA
```

An important commercial search page fails if any critical pillar is materially weak.

## Tier 2 — quality/support

After Tier 1 passes:
- information gain/originality;
- brand credibility/tone;
- visual hierarchy/usability;
- maintainability/performance;
- implementation convenience.

## Common conflict rules

### CRO vs visual convenience
If strong truthful copy wraps to three lines, adapt the design before weakening the message solely to make it prettier.

### Human clarity vs exact-keyword obsession
Prefer clear buyer language. Reinforce search semantics via title, supporting headings, entities, copy and internal links rather than keyword stuffing.

### Desire vs believability
A stronger promise loses if proof cannot support it. Narrow the claim.

### ELI10 vs precision
Keep necessary technical terms, then explain them plainly. ELI10 means immediate comprehension, not childish wording.

### Search demand vs page existence
A keyword does not earn a URL. Distinct user need + business capability + information gain do.

### Brand vs aggressive CRO
Credibility wins over hype. An unbelievable “10X now” claim damages perceived likelihood.

### Owner preference vs recommendation
Owner preference normally wins after the trade-off is clearly explained, unless it violates Tier 0.
