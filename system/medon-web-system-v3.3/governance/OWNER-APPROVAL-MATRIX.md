# Owner Approval Matrix — v3.3

The owner approves **consequential wholes**, not every intermediate artifact.

## Owner decision required

### Commercial
- primary business objective/constraint when ambiguous;
- audience/ICP when materially strategic;
- promoted service hierarchy;
- offer/package architecture;
- final public prices/terms;
- primary conversion mechanism;
- permission for sensitive/quantitative proof claims.

### Search / architecture
- major domain/site split;
- material URL migration/consolidation;
- page portfolio decisions tied to business strategy.

### Technical
- repository/account/data ownership;
- platform/CMS/hosting commitments when trade-offs matter;
- paid third-party commitments;
- lead/data ownership.

### Visual
- materially different visual identity/character;
- final representative-page visual system before site-wide scale.

Typography/palette/geometry may be escalated separately **only when the alternatives create a materially different visible brand outcome**.

## Strategy/Content Agent decides by default
- complete draft wording inside approved strategy;
- eyebrow/support/section heading variants;
- routine CTA wording consistent with approved conversion mechanism;
- argument sequencing and section transitions;
- metadata/internal-link wording;
- which internal content tools to use.

## Design/Implementation Agent decides by default
- spacing corrections inside approved system;
- responsive fit;
- semantic HTML;
- component/file organization;
- icon library consistent with direction;
- schema mechanics reflecting approved visible truth;
- test/lint/build mechanics.

## Interaction rule

Do not ask the owner to choose a micro-variable merely because alternatives exist.

For a material decision:

```text
DECISION
Why it matters
A — ...
B — ...
C — ... (only if genuinely useful)
Recommendation
Trade-off
```

For non-material choices: decide, record if useful, continue.

## No-repeat rule

Do not re-ask a resolved material decision unless the owner explicitly reopens it or new evidence creates a material conflict.
