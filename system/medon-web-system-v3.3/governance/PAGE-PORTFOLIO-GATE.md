# Page Portfolio Gate

Before building a broad IA, rank candidate pages by usefulness and commercial/search role.

## Candidate dimensions

Rate qualitatively or 1–5 where useful:
- distinct user need;
- search demand/intent;
- AIO/retrieval opportunity;
- commercial value;
- information gain;
- first-party/proof readiness;
- same-site overlap;
- cross-channel role;
- implementation effort;
- business capability to satisfy the promise.

## Allowed outcomes

- `BUILD_NOW`
- `BUILD_LATER`
- `MERGE`
- `EXPAND_EXISTING`
- `REDIRECT`
- `DO_NOT_BUILD`

## Cross-channel economics for existing sites

Where data exists, prioritize pages using total business impact:
- organic sessions/queries;
- paid clicks/spend;
- AI/referral visibility;
- conversions;
- lead quality;
- revenue/value;
- CPA/CAC/RPV where meaningful.

Do not spend ten hours polishing a low-impact URL while a high-spend/high-traffic landing page leaks qualified demand.
