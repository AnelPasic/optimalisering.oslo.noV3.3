# Rule Classes

This prevents a 150-item research backlog from becoming a 150-step mandatory checklist.

## CORE

Always applies when logically relevant.

Examples:
- truth before claims;
- one page job;
- real proof provenance;
- important new search pages must earn the URL;
- no PII in Git;
- measurable primary conversion before launch.

## ROUTED

Mandatory only for the matching project/page type.

Examples:
- GBP alignment → Local SEO;
- independent reputation research → important/YMYL/high-stakes commercial topics;
- template health/canary → scaled/programmatic page families;
- source ecosystem mapping → important AIO topics;
- CRO quant+qual → major existing-site redesign when data exists.

## OPTIONAL

The agent may recommend with a rationale.

Examples:
- assessment funnel;
- calculator/tool;
- YouTube distribution;
- risk reversal/guarantee;
- behavioral popup trigger.

## EXPERIMENTAL

Never silently enforced. Must be framed as a test/hypothesis.

Examples:
- unproven formatting preferences;
- third-party correlations without causal support;
- site-specific conversion patterns.

## NEVER-HARD-RULE

Explicitly rejected universal claims remain rejected, including:
- fixed word counts;
- fixed location-page counts;
- fixed number of nav items;
- weekly A/B tests for every site;
- “pretty sites convert worse”;
- “schema is required for AI visibility”;
- fake consensus/reviews/awards;
- exact hidden AI fan-out inference.
