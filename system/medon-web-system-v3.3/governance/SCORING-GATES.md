# Scoring & Multi-Gate Ranking

Do not use one universal “quality score”. A fatal flaw must not be averaged away by cosmetic strengths.

## Evaluation model

```text
CANDIDATES
→ HARD VALIDITY GATES
→ ARTIFACT-SPECIFIC WEIGHTED SCORE
→ MINIMUM FLOORS
→ RED TEAM
→ OWNER CHOICE / CLEAR WINNER
```

## Level 1 — Validity gates

Typical hard gates:
- truth / compliance;
- intent relevance;
- basic clarity;
- proof compatibility for strong claims;
- no contradiction with locked project decisions.

Failure = `DISQUALIFIED` or `REVISE`, not “62/100”.

## Level 2 — Commercial quality

Weights vary by artifact. Never pretend the score is scientific precision; it is a disciplined comparison aid.

### Hero H1 suggested weights

| Factor | Weight |
|---|---:|
| Clarity / ELI10 | 25% |
| ICP + intent relevance | 20% |
| Dream Outcome / desirability | 15% |
| Believability / proof compatibility | 15% |
| Specificity / differentiation | 10% |
| Time/effort/risk advantage | 5% |
| SEO/entity alignment | 5% |
| Visual/readability fit | 5% |

Suggested floors: clarity 8/10; relevance 8/10; proof compatibility 7/10 when the claim implies a result.

### Commercial SEO/AIO page suggested weights

| Area | Weight |
|---|---:|
| Search/AIO intent + findability | 25% |
| Buyer relevance / JTBD | 15% |
| Value Equation | 15% |
| Clarity / ELI10 | 15% |
| Proof / believability | 10% |
| Information gain | 10% |
| Conversion path | 5% |
| Brand/visual hierarchy | 5% |

Minimum floors matter more than total score. A page with SEO/AIO 5/10 does not pass because decoration raises the average.

### Informational page

Prioritize search/AIO intent, answer completeness, information gain, clarity and evidence. Commercial path may be lighter.

### Paid-only landing page

Prioritize traffic-message match, clarity, Value Equation, proof and friction. SEO weight can be lower when organic discovery is not a page job.

## Ranking output

Show 3–5 finalists, not 20 raw candidates.

For each finalist:
- pass/fail gates;
- score by relevant factors;
- one-line strength;
- one-line trade-off.

If top options are close, ask owner. If one is materially stronger, recommend it clearly.
