# CRO / Nordic UX Reference

Canonical process: `research/cro-diagnosis.md`, `design/design-gate.md`, `qa/functional.md`.

## Principles

- CRO starts with diagnosis, not redesign.
- First scroll should clarify what this is, who it is for, why it matters and the next step.
- Reduce action threshold: uncertainty, unnecessary fields, unclear pricing/process, hidden next steps.
- Put relevant proof/risk reduction near doubt.
- Section order follows awareness/traffic intent, not a universal template.
- Headings should carry the story for scanners.
- Design hierarchy makes information hierarchy visible.
- Mobile is a primary context, not desktop squeezed smaller.
- Norwegian/Nordic trust generally favors restraint, specificity and transparency over sales theatre.

Do not hardcode arbitrary counts for nav items, sections, steps or word length.
