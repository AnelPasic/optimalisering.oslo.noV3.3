# Hooks & Copy Reference

Canonical rules: `content/content-copy-standard.md` and `content/message-architecture.md`.

## Hook standard

Clarity first. Relevance second. Curiosity/contrast after that.

Generate multiple candidates and reject:
- vague suspense;
- delayed topic;
- clever but confusing wording;
- unsupported superlatives;
- copy that could fit every competitor.

Optional mechanics:
- Yay without Boo;
- buyer mistake;
- contradiction;
- damaging admission;
- proof-before-promise;
- specific pain moment;
- fit/not-fit;
- decision rule.

Do not treat any formula as mandatory.

Optional raw source for deeper hook ideation: `source-material/raw/KillerHooks.txt`. It is source material, not an authority over verified facts or v3 rules.
