# Pricing / Packaging Reference

Treat separately:

```text
Packaging
Pricing metric
Price point
```

Use actual deal evidence first.

If final prices are unknown:
- propose structure/logic;
- state assumptions;
- do not invent approved prices.

Commercial presentation should make fit, inclusions, limits and external costs clear enough for both humans and machine extraction.

Anchoring is allowed only when truthful. Do not fabricate compare-at/original prices or savings.
