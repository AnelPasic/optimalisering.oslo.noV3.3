# Method Notes

This Medon Web System v3 consolidates lessons from the existing Medon commercial website blueprint plus supplied marketing/SEO/indexation material.

These are **method inputs**, not blanket factual claims about search algorithms.

## Kept

- research before writing;
- proof before promise;
- audience specificity;
- clear/simple language;
- show observable outcomes instead of abstract benefits;
- optional “Yay without Boo” framing;
- clear hooks before clever hooks;
- mini-offers when they reduce conversion friction;
- entity clarity;
- real images/experience where available;
- internal linking;
- non-redundant content;
- first-party data/customer language;
- same-site redundancy checks;
- message architecture before visual design;
- outcome before technical vehicle;
- page quality vs Needs Met;
- functional content as legitimate Main Content;
- AIO retrieval/source mapping and query fan-out;
- evidence-led CRO before redesign;
- assessment result-first + fit routing;
- website-as-an-operated-system after launch;
- template-level indexation monitoring;
- merge/delete as valid outcomes.

## Deliberately not turned into universal rules

- arbitrary “30 page” indexing thresholds;
- guaranteed indexation percentages;
- claims that one CMS/framework receives SEO preference;
- mandatory FAQ/schema on every page;
- mandatory external link counts;
- fixed conversion-rate benchmarks;
- mandatory ratings, guarantees or scarcity;
- unsupported claims that a particular AI crawler/ranking mechanism requires an experimental file;
- rigid “keyword first, brand last” title formulas;
- fixed 150–160 character meta-description requirements;
- “use only the last 7 days of GSC” as a universal rule;
- “schema is mandatory for AI visibility” claims;
- “daily content + daily backlinks” automation as a standing rule;
- automatic keyword-driven URL rewrites;
- fixed hero-form requirements;
- fixed navigation-item counts.

Use current authoritative sources whenever implementation depends on a factual platform/search claim.

## Additional content primitive

- sourced fact/insight blocks may be used when they provide relevant specificity or context;
- fact blocks are not required for every page and are not treated as an SEO ranking tactic;
- volatile facts require current verification.
