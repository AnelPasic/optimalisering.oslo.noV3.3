# Functional Asset / Engineering-as-Marketing Evaluation

Before writing another article, ask whether the user's job is better solved by:
- calculator;
- estimator;
- assessment;
- configurator;
- comparison tool;
- checklist generator;
- template;
- interactive lookup/filter.

A functional asset is worthwhile when it can simultaneously:
- meet real intent;
- provide information gain;
- demonstrate expertise;
- create qualified demand;
- earn citations/mentions/links;
- feed first-party learning.

Do not build a tool merely because interactive content is fashionable. The utility must justify build/maintenance cost.
