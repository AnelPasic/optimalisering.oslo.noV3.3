# Lead Magnets / Mini-Offers

A lead magnet should reduce uncertainty or deliver real value, not merely collect email addresses.

Useful types:
- reveal/diagnose a problem;
- trial/sample;
- one useful step of a larger process;
- calculator/estimator;
- checklist/template;
- assessment.

Qualification questions should improve the user's result as well as the CRM record.

Do not force contact capture before any value when result-first/progressive profiling is clearly better.

For assessments use `integrations/assessment-funnel.md`.
