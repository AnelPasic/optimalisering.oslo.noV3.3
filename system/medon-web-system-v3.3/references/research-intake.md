# Research / Intake Reference

Use `project-discovery.md`, `source-of-truth.md` and `templates/PROJECT-BRIEF.md`.

If given only a URL or Google Business Profile/business identity:
- research first;
- inspect the existing property/entity;
- inspect live market/search evidence where relevant;
- infer only what can reasonably be inferred;
- ask questions only for material conflicts or business facts unavailable externally.

Do not make the user repeat information already supplied in project files.
