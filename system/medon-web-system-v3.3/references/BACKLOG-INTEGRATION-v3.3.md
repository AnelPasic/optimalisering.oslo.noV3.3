# Backlog Integration — v3.3

The canonical/reconciled registry outranks raw backlog notes. Raw backlog remains research/history, not a runtime checklist.

## Preserved from v3.2
- Page Existence / Incremental Value Gate;
- research before writing and first-party evidence priority;
- same-site uniqueness/content-footprint awareness;
- Needs Met distinct from Page Quality;
- functional content/tools where they beat another article;
- AIO retrieval/source mapping and query fan-out where useful;
- truthful corroboration/distribution;
- SEO/AIO + CRO parallel commercial gates;
- Value Equation, certainty/proof proximity, heading-only scan;
- existing-site evidence triangulation;
- choice architecture and functional whitespace;
- assessment funnel when diagnosis creates value;
- evidence registry/confidence, experiment ledger, template canary.

## Promoted in v3.3
- canonical rules must pass duplicate/contradiction/precedence/routing before promotion;
- role ownership: Strategy/Content vs Design vs Implementation vs Owner;
- complete-page content production instead of line-by-line owner gates;
- Git-backed content as inter-agent source of truth;
- Pages CMS as human editor, not separate content authority;
- implementation agent may not invent missing production content/claims/pricing/proof;
- concise project state supports fresh agent sessions;
- controlled visual experiments remain, but visual sub-layers are not automatic owner gates;
- representative full page is the primary visual-system approval before scale.

## Optional / evidence-dependent
Distribution channels, guarantees/risk reversal, popups, test cadence, tools/calculators and other tactics remain routed by real fit/evidence.

## Not hard-coded
Fixed word/page counts, universal funnel benchmarks, fake AI schema/files, fake proof/consensus, geo tricks, fixed UI counts, or automated manipulation.
