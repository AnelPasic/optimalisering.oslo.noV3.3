# Offer & Lead Mechanics

## Offer system

```text
Constraint
→ Dream Outcome
→ likelihood/proof
→ Time-to-Value
→ effort/sacrifice
→ obstacles
→ solution vehicles
→ package structure
→ price
→ risk reduction where real
```

## Lead system

```text
traffic awareness
→ direct CTA OR mini-offer
→ qualification
→ value delivery
→ next action
→ follow-up
→ qualified lead
→ customer/value
```

Do not optimize raw lead volume when lead quality/economics are the real constraint.

## CTA

A CTA should tell the user:
- what to do;
- what happens next;
- why the step is useful.

Use the smallest sensible next step for the visitor's awareness/fit.

## Proof placement

Match proof to the objection at that point in the journey. Random badge walls are not strategy.
