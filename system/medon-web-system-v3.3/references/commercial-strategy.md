# Commercial Strategy Reference

Canonical detailed rules live in `BLUEPRINT.md`, `project-discovery.md` and project `PRODUCT-MARKETING.md`.

## Diagnose before prescribing

Identify the primary constraint before deciding the website needs more traffic, more content or a redesign.

## Customer model

Use:
- ICP / buying role;
- JTBD;
- PUSH / PULL / HABIT / ANXIETY;
- trigger events;
- alternatives;
- objections;
- customer language;
- proof.

## Value Equation lens

Increase value by improving:
- Dream Outcome;
- Perceived Likelihood;
- Time-to-Value;
- Effort/Sacrifice.

Do not merely increase the promise. Often the stronger move is more proof, less uncertainty, less effort and a clearer next step.

## Outcome before vehicle

Customer-facing copy should lead with the outcome/problem/decision, not technology or internal delivery jargon.
