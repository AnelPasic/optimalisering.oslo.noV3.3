# Implementation Agent Execution Contract — v3.3

Default implementation agent: Codex/Claude Code or equivalent repo-native coding agent.

## Before editing

Read:
- `AGENTS.md`;
- project source-of-truth/state;
- relevant decision locks;
- locked content for the pages in scope;
- visual system/representative-page decisions;
- task acceptance criteria.

Inspect the repository before proposing implementation.

## Do not invent

Unless explicitly assigned and supplied an approved content brief, do not invent or materially change:
- positioning;
- service hierarchy;
- package/offer logic;
- public prices/terms;
- proof/results;
- guarantees/urgency;
- production H1/body/CTA strategy;
- page URLs/search roles;
- visual identity direction.

If required content is missing, mark the dependency. Do not fill production with generic agency copy.

## Freedom

Inside locked outcomes, choose the best implementation:
- component boundaries;
- file structure;
- semantic HTML;
- CSS/layout mechanics;
- responsive implementation;
- accessibility fixes;
- build/test tooling;
- content adapters;
- Pages CMS field plumbing;
- performance improvements.

## Completion note

Return/write:

```text
OUTCOME
FILES CHANGED
LOCKS PRESERVED
ASSUMPTIONS
TESTS / BUILD
BROWSER CHECKS
KNOWN GAPS
SCREENSHOTS / EVIDENCE where relevant
```

A green build proves technical consistency, not commercial/design quality. Route completed work to the appropriate Red Team review.
