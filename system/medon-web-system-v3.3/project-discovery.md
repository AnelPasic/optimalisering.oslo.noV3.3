# Project Discovery

Use this before commercial lock.

## 0. Workflow + ownership

- Workflow profile: FAST / STANDARD / ADVANCED / EXISTING_SITE
- Site ownership: MEDON_OWNED / CLIENT_OWNED

## 1. Project type

- [ ] Greenfield
- [ ] Existing production improvement
- [ ] Deliberate rebuild/migration

## 2. Business constraint

What is actually limiting growth?

Examples:
- not enough qualified demand;
- weak conversion;
- poor lead quality;
- low trust;
- unclear offer;
- poor follow-up;
- retention;
- capacity/supply constraint.

Do not automatically prescribe “more traffic”.

## 3. Commercial context

Capture:
- ICP;
- buying roles;
- JTBD;
- trigger events;
- Push / Pull / Habit / Anxiety;
- current alternatives;
- desired outcome;
- obstacles;
- objections;
- current proof;
- existing prices/packages;
- customer acquisition channels;
- sales process;
- source of truth for customers/revenue.

## 4. Customer language

Prioritize actual words from:
- calls;
- emails;
- reviews;
- CRM notes;
- search queries;
- support;
- sales objections.

Do not start copy by reading ten competitors and imitating the category average.

## 5. Services

Lock:
- primary;
- secondary;
- supporting;
- do-not-promote-yet.

## 6. Page / site job

Define the one primary commercial decision the site/homepage should move a qualified visitor toward. Secondary actions may exist, but they must not compete with the primary job at equal visual weight.

## 7. Offer

Define:
- Dream Outcome;
- perceived likelihood/proof;
- Time-to-Value;
- effort/sacrifice;
- delivery mechanism;
- risk/reversal only if credible;
- direct CTA vs mini-offer;
- qualification;
- external costs.

## 8. Brand

If a real brand guide exists, use it.

Otherwise propose 2–3 credible directions and recommend one before design work.

## 9. Unknowns

Maintain explicit unknowns.

A project with unresolved commercial truth should not hide the uncertainty inside polished copy.
