# SEO / AIO QA — paired with CRO

## Intent and usefulness

- [ ] page has a clear user intent;
- [ ] page provides real value beyond consensus;
- [ ] same-site redundancy checked;
- [ ] no keyword/city-swap sludge;
- [ ] direct answers exist where appropriate;
- [ ] decision rules/trade-offs are explicit where useful.

## Entities

- [ ] business identity consistent;
- [ ] service/entity naming coherent;
- [ ] locations only claimed where real;
- [ ] people/credentials verified;
- [ ] internal entity relationships make sense.

## On-page

- [ ] one coherent H1;
- [ ] useful heading hierarchy;
- [ ] title/description specific;
- [ ] canonical correct;
- [ ] internal links useful;
- [ ] external citations where factual context needs them.

## Structured data

- [ ] only relevant supported types;
- [ ] structured data matches visible truth;
- [ ] no fake ratings/reviews;
- [ ] no schema added merely because a checklist said so.

## Crawl/index

- [ ] important page linked internally;
- [ ] included in sitemap where appropriate;
- [ ] index policy deliberate;
- [ ] no JS-only critical copy;
- [ ] post-launch monitoring owner defined.

## Local entity alignment (when relevant)

- [ ] distinguish real physical location from service-area/city page;
- [ ] GBP categories/services/location are compared with actual website content;
- [ ] real location pages carry real NAP/opening-hours/services/people/media where applicable;
- [ ] LocalBusiness schema describes reality;
- [ ] no mechanical one-page-per-GBP-service rule.

## AI visibility

For important AI-search topics, consider retrieval/source mapping and likely query fan-out before assuming a classic “top 10 SERP” model is sufficient.

Focus on:
- crawlability;
- clear entities;
- concise answerable passages;
- first-party facts;
- evidence/provenance;
- useful comparisons;
- consistent public information.

Do not present `llms.txt` or other experimental mechanisms as a proven ranking requirement.

## Metrics language

Do not conflate:
- mention;
- citation/source;
- organic ranking;
- AI visibility;
- referral/click;
- conversion.


## Dual-gate rule

For important commercial search pages, use `qa/SEO-CRO-DUAL-GATE.md`. Strong search optimization cannot compensate for a page that fails buyer understanding/proof/action, and strong CRO cannot compensate for a page that cannot be discovered for its intended search role.
