# Independent Red Team

The Red Team reviews; it does not silently redesign.

## Rule

During a red-team pass the agent may:
- identify failures;
- score against defined gates;
- cite evidence/locked decisions;
- recommend which earlier phase should reopen.

It may **not** silently rewrite the hero, change typography, swap palette, restructure URLs or refactor architecture.

## Review lenses

- Truth/proof
- Search/AIO/Needs Met
- CRO/Value Equation/certainty
- heading-only story
- proof proximity
- choice complexity
- mobile/real-content stress
- visual hierarchy
- functional path
- tech/deployment readiness

## Output

```text
PASS / FAIL

P0 blockers:
P1 material issues:
P2 polish:

Locked decision conflicts:
Evidence:
Recommended phase to reopen:
```

No self-congratulation. A beautiful page with a broken form is a fail.
