# SEO/AIO + CRO Dual Gate

Before visual design of an important commercial search-facing page, both discovery and conversion must pass.

## Model

```text
BE FOUND      → SEO / AIO / intent / entities / crawlability
BE UNDERSTOOD → clarity / Needs Met / ELI10 / hierarchy
BE BELIEVED   → proof / certainty / reputation / provenance
BE CHOSEN     → Value Equation / offer / CTA / low friction
```

## Discovery gate

- search/user intent explicit;
- page deserves its URL;
- entity model coherent;
- information gain real;
- same-site overlap checked;
- important AIO retrieval/source landscape considered where relevant;
- internal linking/page role planned;
- crawl/index requirements feasible.

## Conversion gate

- one page job;
- Value Equation mapped;
- certainty gaps addressed or explicitly flagged;
- major claims have appropriate proof or narrowed wording;
- CTA matches awareness;
- action threshold/friction reasonable;
- heading-only story works;
- section sequence follows buyer questions.

## Pass rule

Do not average a severe discovery failure against a strong CRO score, or vice versa. Both must clear their minimum quality floor before design approval.
