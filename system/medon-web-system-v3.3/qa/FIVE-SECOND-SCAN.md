# Five-Second + Scan Tests

## Hero five-second gate

A qualified non-expert should quickly understand:
- What is this?
- Who is it for / is it relevant to me?
- What useful outcome is offered?
- Why should I care/believe enough to continue?
- What do I do next?

Do not require all proof/objections above the fold. Require orientation.

## Heading-only scan

Hide paragraph copy and inspect only:
- H1/H2/H3;
- key numbers;
- proof labels;
- package labels;
- CTA labels.

The main argument should remain coherent.

## Visual hierarchy tests

Use:
- thumbnail/zoom-out;
- squint/blur;
- desktop + mobile;
- real long Norwegian copy.

The first, second and third priority should remain perceptually clear.
