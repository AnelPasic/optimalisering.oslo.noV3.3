# Content QA

A page fails if it is polished but generic.

## Hard checks

- [ ] Page Brief exists for important pages.
- [ ] page quality and Needs Met were considered separately;
- [ ] visitor can complete the intended job without unnecessary return-to-search/friction;
- [ ] information gain is explicit;
- [ ] first-party evidence used where available;
- [ ] unsupported claims removed;
- [ ] same-site overlap checked;
- [ ] hook is clear and relevant;
- [ ] CTA states what happens next;
- [ ] copy sounds like this business, not the category average;
- [ ] jargon/hype removed;
- [ ] concrete examples/moments used;
- [ ] objections answered honestly;
- [ ] tone is credible for Norway/Nordics.

## Replaceability test

Could a competitor reuse this page by changing:
- logo;
- company name;
- city?

If yes, fail.

## Sentence test

For each major claim ask:
- What exactly does this mean?
- What evidence supports it?
- Can it be shown instead of asserted?
- Is the wording stronger than the evidence?

## Hook test

Reject:
- delayed topic;
- confusing construction;
- irrelevant cleverness;
- curiosity without value;
- generic superlatives.

## Final trim

Remove sections that exist only because “websites usually have this section”.

## Heading-only scan test

Read only H1/H2/H3/CTA labels. The page should still communicate the main result, relevance, differentiation, process/proof and next step.


## v3.3 additional checks

- [ ] Page Contract reflects approved search/commercial role.
- [ ] hard-gated headline candidates were ranked rather than accepting first plausible copy.
- [ ] Value Equation weakness is resolved honestly, not by hype.
- [ ] Certainty Gap identifies unanswered buyer questions.
- [ ] proof is matched to claim/objection and located close enough to help.
- [ ] Section Contracts explain why each major block exists.
- [ ] grayscale structure passed before visual styling.
