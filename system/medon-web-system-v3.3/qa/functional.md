# Functional QA

When functionality is central to the page's purpose, using it is part of content QA.

Test relevant flows end-to-end:
- form submit;
- assessment/quiz;
- calculator/estimator;
- search/filter;
- booking;
- video/playback;
- downloads;
- add-to-cart/checkout where in scope;
- client-side validation;
- confirmation/result state;
- mobile keyboard and form behavior.

Record:
- works / broken;
- dead end;
- misleading CTA;
- validation problem;
- mobile-specific issue;
- tracking/lead-record result.

A functional failure is a content failure when the functionality is the Main Content/job of the page.
