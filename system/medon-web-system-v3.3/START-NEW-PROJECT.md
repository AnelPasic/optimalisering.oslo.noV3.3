## Gate 0 — Project + Technical Foundation
Inspect repo/files/URL. Classify greenfield/existing/migration/microsite/app. Select FAST/STANDARD/ADVANCED. Set MEDON_OWNED/CLIENT_OWNED. Lock framework/CMS/repo/host/deploy/runtime/leads/environments/account ownership enough to proceed.

## Gate 1 — Commercial Truth
Establish actual business constraint, primary buyer/ICP/JTBD, service hierarchy, offer model, primary conversion and proof limits. Ask owner only unresolved material decisions.

## Gate 2 — Search/AIO + Page Portfolio
Research intent/entities/retrieval/information gain. Run Page Existence Gate. Lock meaningful page roles/URLs, not every keyword variation.

## Gate 3 — Content Specification + Production
Assign STRATEGY_CONTENT. For each important page: research → Page Brief/Contract → proof/certainty → argument → complete page draft → SEO/AIO/CRO content QA → content lock. Internal headline/section tools do not become owner micro-gates.

Where Pages CMS is selected, place production content in the Git-backed semantic layer early enough that implementation can consume it.

## Gate 4 — CRO + Information Architecture
Validate heading-only story, persuasion sequence, proof placement, section jobs and grayscale desktop/mobile hierarchy. Resolve routine sequencing autonomously; escalate only material conversion/offer conflicts.

## Gate 5 — Visual Production
Create visual brief; resolve visual system with controlled experiments; produce one representative full page desktop+mobile. Owner approves materially different identity and final representative system, not every token.

## Gate 6 — Implementation
Assign IMPLEMENTATION and use `implementation/CODEX-EXECUTION-CONTRACT.md`. Implementation consumes locked content/design outcomes, chooses code mechanics, integrates CMS/leads/measurement and proves build/browser behavior.

## Gate 7 — Red Team + Launch
Independent commercial/content/design review + technical/functional/SEO/AIO/measurement launch QA. Fix failures in the owning layer. Launch only when blockers are closed.

## First response rule
Do not begin with 20 questions. Inspect available evidence first. Return profile, known truth, unknown material blockers, recommended next coherent batch and only the smallest necessary material decision.

## No-repeat rule
Do not re-ask resolved project truth unless owner reopens it or new evidence creates a material conflict.
