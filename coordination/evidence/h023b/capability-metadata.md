# Explicit composition metadata

Only Synlighet and Konvertering gain `composition`. Fields: `commercialText:true` retains the existing approved commercial-copy binding; `service.closingCta:false` retains their lack of the generic trailing CTA; `service.proofAfter:prioritering` preserves proof placement; `service.pricingBridge` specifies the existing sammenheng anchor, /priser/ source link and unchanged service label; `service.sectionVisuals` maps Konvertering friksjon/kvalitet to its existing behov/kanaler presentation. Synlighet explicitly selects its existing behov/kanaler visuals under the same section names. Both records add `service.sectionSurfaces` with the existing sammenheng section and semantic dark surface. This replaces a family stylesheet palette override with the shared CMS-aware dark adapter; an explicit CMS surface still takes precedence.

The schema is strict, validates every used target against actual ordered sections and requires the existing source link/proof slot. These implementation-owned fields are not routine OWNER presentation choices and are not added to CMS controls. Existing merge:true retains them in saves. They cannot change publication, proof values, offers or prices. All other content fields and every other content record remain exact. No capabilities are invented for SEO, AI or e-commerce.
