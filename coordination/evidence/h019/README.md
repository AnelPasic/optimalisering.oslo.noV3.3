## Renderer / palette

Only the two ordinary section renderers consume the validated `data-surface` attribute. Central H-018 tokens provide each background. Scoped color overrides win against automatic Invite paints; default emits no attribute. A selected dark background sets foreground, muted text, links and dividers automatically. Light cards reset inherited dark text to the captured page palette; automatically painted cards keep light text palettes, while flat rows inherit their selected section's palette. Numbering and legacy paragraph colors follow that palette too. Color-only declarations add no typography, radius, padding, grid, borders widths or shadow changes. Existing typography tokens, surfaces/geometry defaults, centered full-width section headings and uncapped Invite copy stay intact.
