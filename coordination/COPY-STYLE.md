# Customer-facing punctuation style

Date: 2026-10-09
Authority: OWNER

Use ordinary keyboard punctuation in customer-facing copy.

## Required

- Use `-` for dash punctuation.
- Use `->` for textual arrows.
- Keep normal Norwegian letters and punctuation otherwise.

## Avoid in customer-facing copy

- en dash: `–`
- em dash: `—`
- Unicode text arrow: `→`
- decorative Unicode arrow variants when plain text is intended

## Scope

This applies to:
- headings
- body copy
- FAQ
- package copy
- CTA support text
- CMS-editable customer-facing text
- future Norwegian and English content

Actual SVG/icon arrows used as interface graphics are not text punctuation and may remain.

Do not perform blind replacements inside:
- URLs
- code syntax
- identifiers
- SVG path data
- technical source where the character has a functional purpose

Reason: this is the project's preferred human/plain-text house style. Do not make SEO claims from the punctuation rule itself.
